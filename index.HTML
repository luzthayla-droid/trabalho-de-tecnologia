Introdução ao Pensamento Computacional

O que é?

Pensamento Computacional é uma maneira de pensar para resolver problemas de forma lógica, organizada e eficiente.

Ele não significa apenas saber usar um computador. É uma habilidade que pode ser utilizada para resolver problemas do dia a dia.

Na escola

Ajuda os estudantes a organizar ideias, solucionar desafios, desenvolver o raciocínio lógico e compreender melhor problemas complexos.

Na sociedade

Está presente na criação de aplicativos, sistemas, sites, jogos, serviços digitais e também na organização de atividades cotidianas.

Onde é utilizado?

  • 💻 Desenvolvimento de sistemas
  • 🎮 Criação de jogos
  • 📱 Aplicativos
  • 🤖 Inteligência artificial
  • 🏫 Educação
  • 🏠 Situações do cotidiano
02

Decomposição 🧩

🧩

Definição

Decomposição é dividir um problema grande e complexo em problemas menores e mais fáceis de resolver.

Como funciona?

Em vez de tentar solucionar tudo de uma vez, identificamos as partes do problema e resolvemos cada uma delas separadamente.

🏠 Exemplo do cotidiano

Imagine que você precisa organizar uma festa. É possível dividir a tarefa em:

  1. Escolher o local.
  2. Fazer a lista de convidados.
  3. Escolher os alimentos.
  4. Enviar os convites.
  5. Organizar a decoração.

💻 Exemplo na informática

Para criar um site, podemos dividir o projeto em:

  1. Planejar o conteúdo.
  2. Criar o HTML.
  3. Estilizar com CSS.
  4. Adicionar funcionalidades com JavaScript.
  5. Testar o site.
03

Reconhecimento de Padrões 🔍

🔍

Definição

Reconhecimento de padrões é identificar características ou comportamentos que se repetem em diferentes situações.

Explicação

Quando encontramos algo que se repete, podemos utilizar esse conhecimento para resolver novos problemas com mais facilidade.

🌦️ Exemplo do cotidiano

Ao observar o clima durante vários dias, podemos perceber padrões. Por exemplo, se todos os dias chove no final da tarde, podemos nos preparar levando um guarda-chuva.

💻 Exemplo na programação

Em um programa, podemos perceber que determinada tarefa precisa ser repetida várias vezes. Em vez de escrever o mesmo código repetidamente, podemos utilizar um laço de repetição.

repetir 5 vezes
    mostrar("Olá")
04

Abstração 🎯

🎯

Definição

Abstração é destacar as informações mais importantes de um problema e ignorar detalhes que não são necessários naquele momento.

Explicação

A abstração ajuda a diminuir a complexidade. Assim, conseguimos concentrar nossa atenção no que realmente importa.

🗺️ Exemplo

Um mapa é uma forma de abstração. Ele não mostra absolutamente tudo que existe em uma cidade. Em vez disso, apresenta informações importantes, como ruas, avenidas e locais.

Por que é importante?

A abstração facilita a compreensão de problemas complexos e permite criar soluções mais simples, organizadas e eficientes.

05

Elaboração de Algoritmos ⚙️

⚙️

Definição

Um algoritmo é uma sequência organizada de instruções utilizada para resolver um problema ou realizar uma tarefa.

Como funciona?

Primeiro identificamos o problema. Depois, organizamos os passos necessários para chegar ao resultado desejado.

☕ Exemplo em linguagem natural

Preparar um café:

  1. Pegar uma xícara.
  2. Colocar o pó de café no filtro.
  3. Esquentar a água.
  4. Colocar a água no filtro.
  5. Esperar o café passar.
  6. Servir o café.

💻 Exemplo em pseudocódigo

INÍCIO
